# Editorial and SEO maintenance

Repository-safe process documents live here; private analytics, contact, and account records stay with the owner.

- Use `templates/seo/publication-checklist.md` before every canonical publication or substantive update.
- Use `templates/seo/review-inventory.csv` to assign the owner, risk tier, next-review date, and disposition for every canonical page.
- Add a concise, visible correction note to the page for a material correction, and record the same fact in `templates/seo/corrections.md` when it is made.
- Record durable decisions (canonical/redirect, crawler policy, schema, image rights, withdrawal, analytics, syndication) in `templates/seo/decision-register.md`.

Dates are editorial claims: update `date_modified` and `last_modified_at` together only after a substantive review supported by evidence. Monthly technical review covers CI, sitemap/robots, crawl/index errors, broken links, redirects, dependencies, and Core Web Vitals. Quarterly review covers health/model/product/market/research content; twice-yearly covers agentic guidance, profiles, policy, and hubs; durable essays and image rights are reviewed annually.
